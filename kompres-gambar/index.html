Kompres gambar

Kecilkan ukuran JPG, PNG, WEBP dengan slider kualitas atau target ukuran, misalnya di bawah 200 KB. Jalan di browser.

Ada masalah

    Opsi

    Makin rendah, makin kecil file.
    Kalau diisi, slider kualitas diabaikan. Tidak berlaku untuk PNG yang tidak diperkecil resolusinya.

    Yang perlu kamu tahu

    • Diproses di browser kamu. File tidak diunggah ke server.
    • Format masuk: JPG, PNG, WEBP.
    • PNG tanpa kehilangan data, jadi hemat ukurannya kecil. Untuk hemat lebih besar, ubah ke WEBP atau JPG.
    • Kalau hasil malah lebih besar dari file asli, file asli yang dikembalikan.
