Word ke PDF

Ubah DOCX jadi PDF. File diproses di server dan dihapus otomatis maksimal 1 jam.

SegeraTool ini butuh server dan belum aktif. Tool gambar, audio, dan PDF dasar di beranda sudah bisa dipakai.
Ada masalah

    Opsi

    PDF

    Yang perlu kamu tahu

    • Diproses di server dalam wadah terisolasi. File dihapus otomatis paling lama 1 jam setelah selesai.
    • Format masuk: DOCX.
    • Font yang tidak ada di server diganti font mirip, jadi tampilan bisa sedikit bergeser.

    Cara memakai

    Ubah dokumen Word jadi PDF supaya tampilannya sama di semua perangkat, misalnya untuk dikirim sebagai lamaran atau tugas. Tool ini butuh server dan saat ini belum aktif.

    1. Unggah file DOCX, maksimal 25 MB.
    2. Klik Konversi.
    3. Unduh PDF hasilnya.

    Pertanyaan umum

    Kenapa font bisa berbeda?

    Font yang tidak ada di server diganti font yang mirip, jadi tampilan bisa sedikit bergeser.

    Apakah format DOC lama didukung?

    Saat ini hanya DOCX.
