WAV ke MP3

Ubah WAV jadi MP3 di browser. File tidak diunggah.

Ada masalah

    Opsi

    MP3
    Bitrate
    kbps. Tidak berlaku untuk WAV dan FLAC.

    Yang perlu kamu tahu

    • Diproses di browser kamu. File tidak diunggah ke server.
    • Format masuk: WAV.
    • Batas gratis: 50 MB atau 10 menit per file.

    Tool lain

    • Konversi audio
    • M4A ke MP3
    • FLAC ke MP3

    Cara memakai

    WAV tidak terkompres dan ukurannya besar. Ubah ke MP3 untuk mengirim rekaman lewat chat atau email, atau untuk menghemat ruang penyimpanan.

    1. Tarik file WAV ke kotak.
    2. Pilih bitrate: 128 untuk suara, 192 untuk umum, 320 untuk kualitas tinggi.
    3. Klik Konversi dan unduh MP3 hasilnya.

    Pertanyaan umum

    Seberapa kecil hasilnya?

    Jauh lebih kecil. Bitrate 192 kbps biasanya menghasilkan file beberapa kali lebih kecil dari WAV.

    Apakah kualitasnya turun?

    MP3 membuang sebagian detail. Pada 192 kbps ke atas perbedaannya sulit terdengar untuk pemakaian sehari-hari.

    Ruang kerja file yang simpel, rapi, dan siap membantu.
