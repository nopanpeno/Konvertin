M4A ke MP3

Ubah M4A jadi MP3 di browser. File tidak diunggah.

Ada masalah

    Opsi

    MP3
    Bitrate
    kbps. Tidak berlaku untuk WAV dan FLAC.

    Yang perlu kamu tahu

    • Diproses di browser kamu. File tidak diunggah ke server.
    • Format masuk: M4A, AAC.
    • Batas gratis: 50 MB atau 10 menit per file.

    Tool lain

    • Konversi audio
    • WAV ke MP3
    • FLAC ke MP3

    Cara memakai

    Rekaman dari iPhone dan Voice Memos sering berformat M4A. Ubah ke MP3 supaya bisa diputar di perangkat dan aplikasi yang tidak mengenali M4A.

    1. Tarik file M4A atau AAC ke kotak.
    2. Pilih bitrate.
    3. Klik Konversi dan unduh MP3 hasilnya.

    Pertanyaan umum

    Apakah ukuran file berubah banyak?

    Tidak selalu. M4A sudah terkompres, jadi MP3 hasilnya bisa mirip atau sedikit lebih besar.

    Apakah file diunggah?

    Tidak. Prosesnya berjalan di browser.
