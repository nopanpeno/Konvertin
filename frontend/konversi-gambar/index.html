Ubah format gambar

Ubah gambar antar JPG, PNG, WEBP, dan HEIC langsung di browser. File tidak diunggah ke server.

Ada masalah

    Opsi

    Makin rendah, makin kecil file.

    Yang perlu kamu tahu

    • Diproses di browser kamu. File tidak diunggah ke server.
    • Format masuk: JPG, PNG, WEBP, HEIC.
    • Konversi ke PNG tidak memakai slider kualitas, karena PNG tanpa kehilangan data.
    • Gambar transparan yang diubah ke JPG diberi latar putih.

    • JPG ke WEBP

    Cara memakai

    Pakai tool ini kalau satu gambar harus berganti format: foto HEIC dari iPhone yang tidak terbuka di komputer lama, PNG besar yang mau dijadikan WEBP untuk situs, atau JPG yang butuh latar transparan. Semua diproses di browser, jadi foto pribadi tidak keluar dari perangkatmu.

    1. Tarik gambar ke kotak, atau tempel dengan Ctrl+V. Sampai 10 file sekaligus.
    2. Pilih format tujuan: JPG, PNG, atau WEBP. Geser kualitas kalau ingin file lebih kecil.
    3. Klik Konversi, lalu unduh satu file atau semuanya sebagai ZIP.

    Pertanyaan umum

    Format mana yang sebaiknya saya pilih?

    JPG cocok untuk foto dan dibuka di mana saja. PNG cocok untuk gambar dengan teks atau bagian transparan. WEBP biasanya paling kecil untuk dipakai di situs web.

    Apakah kualitas gambar turun?

    Ke PNG tidak ada penurunan, karena PNG tanpa kehilangan data. Ke JPG dan WEBP kualitas bergantung pada slider. Makin rendah angkanya, makin kecil file dan makin terlihat penurunannya.
