Kebijakan privasi

File dokumen Anda

  • Konversi dokumen (PDF, DOCX, PPTX, XLSX) dilakukan di server kami. File Anda diunggah lewat HTTPS.
  • File asli dihapus segera setelah diproses. Hasil konversi dihapus otomatis maksimal 1 jam setelah dibuat. Anda juga bisa membatalkan proses, yang langsung menghapus file terkait.
  • Nama file di penyimpanan diacak. Proses berjalan di wadah terisolasi tanpa akses internet.
  • Tidak ada manusia yang membaca isi file Anda. Isi file tidak dicatat di log.

Data yang dicatat

  • Catatan teknis job: jenis konversi, status, waktu, dan pesan galat. Dihapus bersama file.
  • Alamat IP dipakai sementara di memori untuk pembatasan frekuensi (maks 20 konversi per jam).
