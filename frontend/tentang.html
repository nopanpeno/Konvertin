Tentang Konvertin

Konvertin adalah konverter file berbahasa Indonesia untuk pekerjaan sehari-hari: mengubah format gambar dan audio, memperkecil ukuran gambar, serta mengubah dokumen PDF, Word, PowerPoint, dan Excel.

Kenapa dibuat

Konvertin bisa dipakai tanpa akun, dan sebisa mungkin file tidak meninggalkan perangkatmu. Akun opsional menyimpan riwayat metadata konversi, bukan file.

Cara kerjanya

  • Gambar dan audio diproses di browser. File tidak diunggah ke server kami.
  • Dokumen membutuhkan server. Jika backend tersedia, file diproses di wadah terisolasi dan dihapus otomatis paling lama 1 jam setelah selesai.

Rincian lengkap ada di kebijakan privasi.

Pembuat

Konvertin dibuat oleh seorang mahasiswa sebagai proyek kuliah, dan dikembangkan terbuka di GitHub. Masukan dan laporan masalah bisa dikirim lewat halaman kontak.

Batasan yang jujur

Hasil konversi bisa berbeda dari file asli, terutama PDF ke Word. Periksa hasilnya sebelum dipakai untuk hal penting. Tidak ada OCR, jadi PDF hasil scan belum didukung.

Ruang kerja file yang simpel, rapi, dan siap membantu.
