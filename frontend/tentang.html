Tentang Konvertin

Konvertin adalah konverter file berbahasa Indonesia untuk pekerjaan sehari-hari: mengubah format gambar dan audio, memperkecil ukuran gambar, serta (segera) mengubah dokumen PDF, Word, PowerPoint, dan Excel.

Kenapa dibuat

Banyak situs konverter meminta kita mengunggah file ke server yang tidak jelas, memasang iklan di sekitar tombol unduh, atau mewajibkan akun. Konvertin dibuat dengan arah sebaliknya: tanpa akun, dan sebisa mungkin file tidak meninggalkan perangkatmu.

Cara kerjanya

  • Gambar dan audio diproses di browser. File tidak diunggah ke server kami.
  • Dokumen membutuhkan server. Tool ini belum aktif. Saat aktif, file diproses di wadah terisolasi dan dihapus otomatis paling lama 1 jam setelah selesai.

Rincian lengkap ada di kebijakan privasi.

Pembuat

Konvertin dibuat oleh seorang mahasiswa sebagai proyek kuliah, dan dikembangkan terbuka di GitHub. Masukan dan laporan masalah bisa dikirim lewat halaman kontak.

Batasan yang jujur

Hasil konversi bisa berbeda dari file asli, terutama PDF ke Word. Periksa hasilnya sebelum dipakai untuk hal penting. Tidak ada OCR, jadi PDF hasil scan belum didukung.
