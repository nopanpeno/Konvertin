Gabung PDF

Gabungkan beberapa file PDF jadi satu langsung di browser. File tidak diunggah ke server.

Ada masalah

    Opsi

    PDF

    Yang perlu kamu tahu

    • Diproses di browser kamu. File tidak diunggah ke server.
    • Format masuk: PDF.
    • Urutan file di daftar menentukan urutan halaman. Pakai tombol naik dan turun untuk mengubahnya.
    • PDF yang dikunci password tidak bisa digabung. Buka kuncinya dulu.

    Cara memakai

    Gabung PDF berguna saat satu berkas harus terdiri dari beberapa dokumen: lamaran beserta lampiran, bab-bab laporan, atau scan yang terpisah. Semua diproses di browser, jadi dokumen pribadi tidak diunggah.

    1. Tarik dua file PDF atau lebih ke kotak.
    2. Atur urutannya dengan tombol naik dan turun di tiap baris.
    3. Klik Konversi, lalu unduh PDF gabungan.

    Pertanyaan umum

    Berapa file yang bisa digabung sekaligus?

    Sampai 10 file per proses, masing-masing maksimal 50 MB.

    Apakah PDF berpassword bisa digabung?

    Tidak. Buka kunci password di aplikasi lain dulu, lalu gabungkan.

    Ruang kerja file yang simpel, rapi, dan siap membantu.
