Kompres gambar

Kecilkan ukuran JPG, PNG, WEBP dengan slider kualitas atau target ukuran, misalnya di bawah 200 KB. Jalan di browser.

Ada masalah

    Opsi

    Makin rendah, makin kecil file.
    Kalau diisi, slider kualitas diabaikan. Tidak berlaku untuk PNG yang tidak diperkecil resolusinya.

    Yang perlu kamu tahu

    • Diproses di browser kamu. File tidak diunggah ke server.
    • Format masuk: JPG, PNG, WEBP.
    • PNG tanpa kehilangan data, jadi hemat ukurannya kecil. Untuk hemat lebih besar, ubah ke WEBP atau JPG.
    • Kalau hasil malah lebih besar dari file asli, file asli yang dikembalikan.

    Tool lain

      Cara memakai

      Kompres gambar saat file terlalu besar untuk diunggah atau dikirim. Kamu bisa mengatur kualitas dengan slider, atau mengisi target ukuran dalam KB supaya tool mencari kualitas yang pas.

      1. Tarik gambar ke kotak.
      2. Atur kualitas, atau isi target ukuran dalam KB.
      3. Klik Konversi. Tool menampilkan berapa persen file menyusut, lalu unduh hasilnya.

      Pertanyaan umum

      Kenapa kompres PNG hematnya kecil?

      PNG menyimpan gambar tanpa kehilangan data. Untuk hemat lebih besar, ubah ke WEBP atau JPG, atau kecilkan resolusinya.

      Bagaimana kalau hasilnya malah lebih besar?

      Kalau itu terjadi, file asli yang dikembalikan, jadi kamu tidak mendapat file yang lebih buruk.

      Ruang kerja file yang simpel, rapi, dan siap membantu.
