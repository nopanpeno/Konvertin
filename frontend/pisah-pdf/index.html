Pisah PDF

Ambil halaman tertentu dari PDF, atau pecah jadi satu file per halaman, langsung di browser. File tidak diunggah.

Ada masalah

    Opsi

    PDF
    Cara pisah
    Angka dan rentang, dipisah koma.

    Yang perlu kamu tahu

    • Diproses di browser kamu. File tidak diunggah ke server.
    • Format masuk: PDF.
    • Tulis halaman dengan angka dan rentang, misalnya 1-3, 5, 8-10.
    • Mode semua halaman menghasilkan satu ZIP berisi satu PDF per halaman.
    • PDF yang dikunci password tidak bisa diproses. Buka kuncinya dulu.

    Cara memakai

    Pisah PDF dipakai untuk mengambil beberapa halaman saja dari berkas panjang, misalnya satu bab, atau untuk memecah PDF jadi satu file per halaman. Prosesnya di browser, tanpa unggah.

    1. Tarik satu file PDF ke kotak.
    2. Pilih Ambil halaman lalu tulis nomor halaman, misalnya 1-3, 5. Atau pilih Semua halaman untuk satu file per halaman.
    3. Klik Konversi, lalu unduh PDF atau ZIP hasilnya.

    Pertanyaan umum

    Bagaimana cara menulis halaman?

    Pakai angka dan rentang yang dipisah koma, misalnya 1-3, 5, 8-10. Halaman yang diambil muncul sesuai urutan yang kamu tulis.

    Apa isi ZIP pada mode semua halaman?

    Satu file PDF untuk tiap halaman, dengan nama yang diberi nomor halaman.
