Kompres Word

Kecilkan ukuran dokumen Word (DOCX) dengan memperkecil gambar di dalamnya. 3 level: ringan, sedang, maksimal. File dihapus otomatis maksimal 1 jam.

SegeraTool ini butuh server dan belum aktif. Tool gambar dan audio di beranda sudah bisa dipakai.
Ada masalah

    Opsi

    DOCX
    Level kompres
    Maksimal paling kecil, kualitas gambar turun.

    Yang perlu kamu tahu

    • Diproses di server dalam wadah terisolasi. File dihapus otomatis paling lama 1 jam setelah selesai.
    • Format masuk: DOCX.
    • Yang diperkecil hanya gambar JPG dan PNG di dalam dokumen. Teks, tabel, dan tata letak tidak berubah.
    • Dokumen tanpa gambar hampir tidak berkurang ukurannya.
    • Level maksimal membatasi sisi terpanjang gambar sekitar 1024 px. Kalau hasil malah lebih besar, file asli yang dikembalikan.
