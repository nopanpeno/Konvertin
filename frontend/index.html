Privasi

Lewat server kami

Konversi dokumen (PDF, Word, PowerPoint, Excel) butuh LibreOffice dan tool lain di server, jadi file diunggah ke server kami. Diproses di wadah terisolasi tanpa akses internet, nama file di penyimpanan diacak, dan tidak ada orang yang membaca isinya.

Kapan dihapus

File asli dihapus segera setelah diproses. Hasil konversi dihapus otomatis maksimal 1 jam setelah dibuat. Tool gambar dan audio yang menyusul akan diproses di browser Anda.

FAQ

Apakah PDF hasil scan bisa diubah ke Word?

Belum. PDF hasil scan butuh OCR dan itu belum ada di versi ini. Kami menolaknya dengan pesan jelas, bukan menghasilkan dokumen kosong.

Kenapa hasil PDF ke Word layoutnya berubah?

PDF menyimpan posisi teks, bukan paragraf. Dokumen sederhana biasanya rapi; tabel rumit dan banyak kolom bisa bergeser. Cek hasilnya sebelum dikirim.

Apakah file .doc, .xls, .ppt lama didukung?

Belum. Simpan ulang sebagai .docx, .xlsx, atau .pptx dari aplikasi Office.

Bagaimana dengan file ber-password?

Ditolak dengan pesan jelas. Buka kuncinya dulu, lalu unggah lagi.

Kapan tool gambar dan audio tersedia?

Segera. Tool yang belum jadi diberi label "Segera" di daftar di atas.
