Kebijakan privasi

Terakhir diubah 15 Oktober 2026. Tinjau ulang sebelum rilis publik, terutama bagian iklan dan cookie.

Yang diproses di browser

Konversi gambar, kompres gambar, ubah ukuran gambar, konversi audio, gabung PDF, pisah PDF, dan gambar ke PDF berjalan sepenuhnya di browser kamu. File tidak dikirim ke server kami. Untuk konversi audio, browser memuat mesin pemroses (ffmpeg.wasm) dari situs ini sendiri, bukan dari pihak ketiga, lalu menyimpannya di browser.

Yang lewat server

Konversi dokumen (PDF ke Word, Word, PowerPoint, Excel ke PDF) dan kompres PDF, Word, PowerPoint membutuhkan server. File kamu diunggah, diproses di wadah terisolasi tanpa akses internet, dan hasilnya tersedia untuk kamu unduh.

  • File input dan hasil dihapus otomatis paling lama 1 jam setelah selesai.
  • Nama file di penyimpanan diacak.
  • Kami tidak membaca isi file, dan isi file tidak dicatat di log.
  • Kami mencatat jenis konversi, status, dan waktu. Alamat IP dipakai sementara di memori untuk pembatasan laju dan tidak disimpan di database.

Akun

Kamu dapat memakai tool tanpa akun. Sistem mencatat jumlah konversi browser dan server secara agregat, termasuk penggunaan tanpa akun. Jika mendaftar, kami menyimpan email, nama tampilan, dan hash password untuk mengelola akun. Sesi masuk disimpan dalam cookie HttpOnly. Untuk akun login, riwayat mencatat jenis tool, sumber proses (browser/server), status, dan waktu; nama file serta isi file tidak dicatat. Riwayat disimpan sampai 1 tahun. File hasil tetap dihapus otomatis paling lama 1 jam setelah selesai.

Admin hanya dapat melihat jumlah penggunaan agregat per hari dan jenis tool, tanpa akses ke file atau riwayat per pengguna.

Iklan dan cookie

Situs ini direncanakan menampilkan iklan lewat Google AdSense. Saat iklan aktif, Google dapat memakai cookie untuk menampilkan iklan, dan kami akan menampilkan banner persetujuan cookie. Bagian ini harus diperbarui saat iklan dipasang.
