Kebijakan privasi

Terakhir diubah 15 Oktober 2026. Tinjau ulang sebelum rilis publik, terutama bagian iklan dan cookie.

Yang diproses di browser

Konversi gambar, kompres gambar, ubah ukuran gambar, upscale gambar, konversi audio, gabung PDF, pisah PDF, dan gambar ke PDF berjalan sepenuhnya di browser kamu. File tidak dikirim ke server kami. Untuk konversi audio, browser memuat mesin pemroses (ffmpeg.wasm) dari situs ini sendiri, bukan dari pihak ketiga, lalu menyimpannya di browser.

Privasi versi GitHub Pages

Versi GitHub Pages ini hanya menyediakan tool yang berjalan di browser. Tool yang memerlukan server belum aktif.

Tool browser memproses file di perangkatmu. File tidak dikirim ke server Konvertin.

Akun

Fitur akun, riwayat, dan dashboard admin belum tersedia di situs GitHub Pages ini.

Iklan dan cookie

Situs ini direncanakan menampilkan iklan lewat Google AdSense. Saat iklan aktif, Google dapat memakai cookie untuk menampilkan iklan, dan kami akan menampilkan banner persetujuan cookie. Bagian ini harus diperbarui saat iklan dipasang.
