PowerPoint ke ODP

Ubah presentasi PPTX menjadi ODP dengan LibreOffice.

Ada masalah

    Opsi

    ODP

    Yang perlu kamu tahu

    • Diproses di server dalam wadah terisolasi. File dihapus otomatis paling lama 1 jam setelah selesai.
    • Format masuk: PPTX.
    • Animasi, font, dan tata letak dapat berubah bila tidak didukung ODP.
