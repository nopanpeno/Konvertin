Upscale gambar

Perbesar resolusi gambar 2x atau 4x dengan model AI langsung di browser. File tidak diunggah ke server.

Ada masalah

    Opsi

    Makin rendah, makin kecil file.
    Skala
    4x lebih lambat dan butuh memori lebih besar.

    Yang perlu kamu tahu

    • Diproses di browser kamu. File tidak diunggah ke server.
    • Format masuk: JPG, PNG, WEBP, HEIC.
    • Cocok untuk gambar kecil yang mau dibesarkan. Hasilnya lebih halus daripada diperbesar biasa, tetapi tidak menambah detail yang memang tidak ada.
    • Hasil dibatasi 12 juta piksel. Skala 2x menerima gambar sampai sekitar 3 juta piksel, skala 4x sampai sekitar 0,75 juta piksel.
    • Mesin dan model sekitar 3 MB diunduh sekali, lalu disimpan browser. Prosesnya memakai kartu grafis lewat WebGL, jadi di perangkat lama bisa lambat.
    • Bagian transparan PNG dipertahankan. Ke JPG, bagian transparan jadi putih.

    Tool lain

    • Konversi gambar
    • HEIC ke JPG

    • PNG ke JPG

    Cara memakai

    Pakai Upscale gambar untuk membesarkan gambar kecil, misalnya foto lama, ikon, atau tangkapan layar beresolusi rendah, supaya lebih layak dicetak atau dipakai di layar besar. Prosesnya memakai model jaringan saraf yang berjalan di browser, jadi gambar tidak diunggah ke server. Hasilnya lebih halus daripada diperbesar biasa, tetapi model ini ringan, jadi jangan berharap detail baru muncul.

    1. Tarik gambar ke kotak, atau tempel dengan Ctrl+V.
    2. Pilih skala 2x atau 4x, dan format hasil. PNG paling aman untuk kualitas.
    3. Klik Konversi dan tunggu bilah proses selesai. Pertama kali, mesin sekitar 3 MB diunduh dulu.
    4. Unduh gambar hasil.

    Pertanyaan umum

    Apakah gambar saya diunggah?

    Tidak. Model dan mesinnya dijalankan di browser kamu. Hanya file mesin dan model yang diunduh dari situs ini, sekali saja.

    Kenapa gambar besar ditolak?

    Hasil dibatasi 12 juta piksel supaya browser tidak kehabisan memori. Skala 2x menerima gambar sampai sekitar 3 juta piksel, dan 4x sampai sekitar 0,75 juta piksel. Kecilkan dulu lewat Ubah ukuran, atau pilih skala lebih kecil.

    Kenapa prosesnya lambat?

    Model berjalan di kartu grafis lewat WebGL. Di perangkat tanpa dukungan itu, prosesnya jatuh ke prosesor dan jauh lebih lambat. Skala 2x lebih cepat daripada 4x.

    Apakah hasilnya setajam Real-ESRGAN atau aplikasi desktop?

    Tidak. Model yang dipakai sengaja ringan agar muat di browser dan di halaman statis. Hasilnya lebih halus dari pembesaran biasa, tetapi tidak sekuat model besar.
