Word ke PDF

Ubah dokumen Word (.docx) jadi PDF yang tampilannya sama di semua perangkat.

Perlu diketahui.

Hanya format .docx. File .doc lama: buka di Word, simpan sebagai .docx dulu.

Font yang tidak ada di server diganti font mirip, jadi baris bisa bergeser sedikit.

    HasilPDF (satu format, tanpa opsi tambahan)Dihapusotomatis maks 1 jam setelah selesai

    Caranya

    1. UploadPilih atau tarik file .docx.
    2. KonversiKlik Konversi, tunggu progress selesai.
    3. DownloadUnduh hasil PDF.

    Pertanyaan

    Kenapa .doc ditolak?

    Format .doc lama tidak didukung di versi ini. Simpan ulang sebagai .docx dari Word.

    Dokumen saya ada password.

    File terproteksi password ditolak. Buka kuncinya dulu di Word, simpan, lalu unggah.
